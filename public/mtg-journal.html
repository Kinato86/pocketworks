Android app · Magic: The Gathering

MTG Journal

A Commander life counter and game journal. One phone runs the whole table, and every finished game becomes history the playgroup can dig through.

React NativeExpoAndroidSupabase

What it does

  • One phone, whole tableLife totals, commander damage, poison counters and eliminations for every seat, all on a single shared device passed around the table.
  • A journal, not just a counterWhen a game ends it is saved with players, commanders and result, so the group builds up a history instead of forgetting who won last month.
  • AnalyticsWin rates per player, per commander and per color identity, straight from the games you actually played.
  • Shared historyFinished games are uploaded to a shared database the whole playgroup reads. Only the game in progress and games waiting to upload stay on the phone.

Under the hood

Built with Expo and React Native on Android, pinned to the SDK the store version of Expo Go runs. Game history lives in Supabase; the live game is local so a dropped connection never interrupts play.
